# EX2 Drive TH updates

Public release channel for EX2 Drive TH for Geely EX2 / EX2 Max in Thailand.

Download `ex2_drive_th_installer.apk` from the latest release for first installation. This Setup APK includes the main app and Helper. The app uses the release channel for manual Wi-Fi updates; users do not need to enter a URL. Keep the vehicle parked in P throughout an update.

Each release includes the signed main, Helper and Setup APKs, SHA-256 checksums, version metadata, release notes and the corresponding source snapshot. Development history and local signing credentials are not distributed here. See the release LICENSE and corresponding-source.zip for the application source; third-party assets retain their own licenses.

Version 1.0.1 adds the Android 9 APK import fix, Home energy simplification, screen rest, lock-sound diagnostics and the manual update client. Physical vehicle compatibility and exterior custom lock-sound playback still require vehicle validation.
