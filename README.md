# EX2 Drive TH OTA

ช่องทางดาวน์โหลดและอัปเดต EX2 Drive TH สำหรับ Geely EX2 / EX2 Max รุ่นประเทศไทย

**ติดตั้งลงรถ:** ดาวน์โหลด [EX2 Drive TH Setup รุ่นล่าสุด](https://github.com/gappa55/ex2-drive-th-updates/releases/latest/download/ex2_drive_th_installer.apk) ไฟล์เดียว ซึ่งรวมแอปหลักและ Helper

หลังติดตั้ง ให้เชื่อมต่อ Wi-Fi แล้วไปที่ **ระบบ → อัปเดตซอฟต์แวร์ → อัปเดต** และคงเกียร์ P ตลอดการติดตั้ง

ตั้งแต่รุ่น 1.0.2 แอปตรวจข้อมูลเวอร์ชันอัตโนมัติผ่าน Wi-Fi ขณะเปิดแอปทุก 6 ชั่วโมง เปิด/ปิดได้ในหน้าอัปเดตซอฟต์แวร์ การดาวน์โหลดและติดตั้งเริ่มเมื่อผู้ใช้กดอัปเดต

Repository นี้เก็บเฉพาะช่องทาง OTA แคตตาล็อกแอป เอกสาร และประกาศสิทธิ์

Release ประกอบด้วย APK แอปหลัก, Helper, Setup, ข้อมูลเวอร์ชัน, SHA-256, บันทึกการเปลี่ยนแปลง และประกาศสิทธิ์ ส่วนปุ่ม Source code (zip/tar.gz) ที่ GitHub สร้างอัตโนมัติเป็นเพียงสำเนาเอกสารและข้อมูลแคตตาล็อกของ repository นี้

Application code retains its existing GPLv3 license. See LICENSE and THIRD-PARTY-ASSETS.md for licensing notices.

## แคตตาล็อก APK

ไฟล์ `catalog.json` เป็นรายการแอปสำหรับเมนู APK ของ EX2 Drive TH พร้อมเวอร์ชัน ขนาด SHA-256 และลายเซ็นที่ต้องตรงก่อนติดตั้ง มี Spotify 9.1.82.2160 ซึ่งเจ้าของรถยืนยันว่าเปิดและเล่นเพลงบน Geely EX2 IHU629G / Android 9 ได้แล้ว และ MicroG RE 7.1.1 (arm64-v8a) ที่ยืนยันว่าติดตั้งบนรถได้ ไฟล์คงลายเซ็นเดิมและไม่ได้ดัดแปลง

MicroG ระบุสถานะ “ทดสอบเฉพาะการติดตั้ง” อาการ YouTube ค้างยังไม่ได้รับการยืนยันว่าแก้ได้ แอปจะตรวจแพ็กเกจและลายเซ็นที่ติดตั้งอยู่เพื่อไม่ดาวน์โหลดรุ่นเดิมซ้ำ กด **ติดตั้ง APK → รีเฟรชรายการ** เพื่อโหลดรายการล่าสุด ไม่มีการติดตั้ง MicroG อัตโนมัติเมื่ออัปเดต EX2

ไฟล์แอปใน `catalog-v1` แยกจากรุ่นอัปเดต EX2 และไม่เปลี่ยนปลายทาง OTA latest แอปภายนอกเป็นของผู้พัฒนาเดิม; โครงการนี้ไม่ใช่ตัวแทนของ Spotify หรือ MorpheApp

แคตตาล็อกในรุ่น 1.0.2 ปรับเป็น 2–3 คอลัมน์เมื่อมีหลายแอปตามพื้นที่หน้าจอ พร้อมเมนูลบสำเนา APK และถอนการติดตั้งแอป

## รุ่น 1.0.3

แคตตาล็อกตรวจแอปที่ติดตั้งแล้วและใช้ไฟล์ที่เก็บไว้แทนการดาวน์โหลดซ้ำ เพิ่มการเปิดสิทธิ์ติดตั้งสำหรับจอที่ไม่มีหน้าตั้งค่าสิทธิ์ โดยต้องมีการเชื่อมต่อภายในที่ได้รับอนุญาตอยู่แล้วและตรวจผลจาก Android เพิ่มเมนู **การเชื่อมต่อ → เปิดการตั้งค่า Wi-Fi** และปรับการ์ดหน้า Home ให้เห็นปุ่มคืนค่าเริ่มต้นโดยไม่ต้องเลื่อนบนจอแนวนอน 1920×1080

ผ่านการทดสอบอัตโนมัติ 500 เคสและตรวจบนอีมูเลเตอร์ ยังต้องยืนยันการเปิดสิทธิ์บนเฟิร์มแวร์รถจริง

## รุ่น 1.0.4

นำเมนูเสียงล็อกรถออกจากหน้าประตูและกระจก รวมการเลือกเสียง ฟังตัวอย่าง ใช้เสียง คืนค่าเสียง และรายงานตรวจเสียง เนื่องจากเสียงกำหนดเองยังใช้งานกับลำโพงภายนอกบนรถจริงไม่ได้ การควบคุมประตูและกระจกยังอยู่ครบ การอัปเดตนี้ไม่เปลี่ยนการตั้งค่าเสียงที่รถใช้อยู่ และเก็บข้อมูลคืนค่าจากรุ่นก่อนหน้าไว้

ผ่านการทดสอบอัตโนมัติ 500 เคสและตรวจหน้าประตูและกระจกบนอีมูเลเตอร์ภาษาไทย/อังกฤษ โหมดสว่าง/มืด

## รุ่น 1.0.5

เพิ่มปุ่มไฟสร้างบรรยากาศบนหน้า Home พร้อมสถานะจากรถ และเปิดกลับที่ความสว่างเดิม รองรับภาษาไทย/อังกฤษและโหมดสว่าง/มืด ปุ่มจะแสดงว่าไม่พร้อมใช้งานเมื่ออ่านสถานะไม่ได้ และแจ้งเมื่อรถไม่ยืนยันการเปลี่ยนไฟ

ผ่านการทดสอบอัตโนมัติ 527 เคส ตรวจลายเซ็นสำหรับ Android API 28 และตรวจหน้า Home บนอีมูเลเตอร์แล้ว การควบคุมไฟยังต้องทดสอบกับฮาร์ดแวร์และสิทธิ์ของจอ Geely EX2 ไทยจริง

## รุ่น 1.0.6

ถอดปุ่มไฟสร้างบรรยากาศจากหน้า Home หลังทดสอบบนรถจริงแล้วไฟไม่ติด ให้ใช้เมนูไฟเดิมของรถ ปรับการตรวจผู้ใช้ Android ด้วยชื่อแพ็กเกจและ UID สำหรับจอที่ไม่มีรายการผู้ใช้รูปแบบปกติ และตรวจทางติดตั้ง APK อีกครั้งก่อนเปิดสิทธิ์ เพิ่ม **ผลตรวจการติดตั้ง → คัดลอกรายงาน** สำหรับตรวจข้อผิดพลาดจากรถ

ผ่านการทดสอบอัตโนมัติ 507 เคส ตรวจลายเซ็น APK สำหรับ Android API 28 และตรวจหน้า Home / รายงานทั้งโหมดสว่างและมืดบนอีมูเลเตอร์แล้ว การเปิดสิทธิ์สำเร็จบนอีมูเลเตอร์ API 33 แต่การติดตั้ง Maps บน IHU629G จริงยังต้องทดสอบอีกครั้ง
